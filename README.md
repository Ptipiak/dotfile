# [Neovim](https://github.com/neovim/neovim)
## plugins
They are managed through [Lazy](https://github.com/folke/lazy.nvim)
## goals
Provide most basic tools a modern IDE could such as auto completion for languages, fuzzy finding of files and definition.
## functions
* LSP and Linter through [Mason](https://github.com/williamboman/mason.nvim)
* Completion through [Coq](https://github.com/ms-jpq/coq_nvim)
* Fuzzy finding through [Telescope](https://github.com/nvim-telescope/telescope.nvim)
* Local file system editing through [Oil](https://github.com/stevearc/oil.nvim)
* Git commit edition through [diffview.nvim](https://github.com/sindrets/diffview.nvim)
